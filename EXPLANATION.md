Smart coworking API 
Serializer - это базовый класс в drf для "перевода" в формат JSON и обратно
ModelSerializer - это расширение которое автоматически сопостовляет поля 

Mixins - это вспомогательные классы такие как CreateModelMixin

Запретить можно методом get_queryset()

GET - выводит списком
POST - создает 
PUT - изменяет целиком  
PATCH - частичное изменение
DELETE - удаление

Запретить можно через поле read_only=True

Кэширование сохраняет тяжелые или частые результаты запросов в RAM

Swagger - это интерактивная веб-страница со всеми доступными API для фронтенда
